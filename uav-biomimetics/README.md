# Литература: биомиметические БПЛА (блок 1)

`block1_literature.csv` - единая таблица: 31 исходная позиция (№1-31) и 22 добавленные (№32-53).

Статусы проверки:
- "подтверждено веб-поиском" - автор, название, том/страницы (и DOI, где он был в выдаче) совпали с найденной записью.
- "не проверено (сеть)" - в окружении заблокированы Crossref, OpenAlex, doi.org, Semantic Scholar; позиция не сверялась.
- "НЕ НАЙДЕНО поиском" - №21, №22 (2026): не цитировать до ручной проверки.
- "КОНФЛИКТ" - №28: два разных DOI в выдаче.
- "DOI из памяти, не проверен" - DOI добавленных работ.

Для полной проверки разрешите хосты api.crossref.org и api.openalex.org в сетевой политике окружения и повторите прогон.
